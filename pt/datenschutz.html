Política de proteção de dados

Princípio

Levamos a sério a proteção dos seus dados pessoais. Tratamo-los de forma confidencial e de acordo com a legislação de proteção de dados e esta política.

Recolha de dados neste site

Este site não utiliza cookies nem tecnologias de rastreamento. Não recolhemos dados pessoais, exceto se nos os enviar voluntariamente por e-mail.

Mensagens por e-mail

O formulário não guarda nada neste site; prepara uma mensagem para nós no seu programa de e-mail. Se nos escrever, guardamos os seus dados, incluindo os contactos, para tratar o pedido e para eventuais perguntas posteriores.

Mapas

Para o mapa de acesso integramos um excerto do OpenStreetMap. Quando o mapa é apresentado, o seu endereço IP é transmitido aos servidores do OpenStreetMap.

Encriptação SSL/TLS

Por motivos de segurança e para proteger a transmissão de conteúdos confidenciais, este site utiliza encriptação SSL/TLS.

Os seus direitos

Tem o direito de ser informado sobre os dados guardados sobre si. Se tiver perguntas sobre a recolha, o tratamento ou a utilização dos seus dados pessoais, contacte-nos.
